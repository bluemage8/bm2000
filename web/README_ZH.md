# 桥牌大师 2000 -- 网页版

**[English](README.md) · 简体中文**

桌面版 `bm2000` 的忠实网页复刻版。相同的 5 个等级与牌例、相同的游戏模型
（你 = 庄家（南家）+ 明手（北家），电脑打西/东的防守）、相同的教学讲解、
相同的“收墩”节奏、相同的 **完成 / 未成（DEAL / FAILED）** 结算弹窗。
整个应用放在一个固定的 **794×547** “窗口”里，用 CSS `transform: scale()`
**等比缩放**以适配浏览器窗口（不拉伸、不变形）。

界面为 **中 / 英 双语**，并能 **根据你的浏览器 / 终端语言自动切换**
（见下方[语言](#语言--中英)）。

## 运行

```
cd web
py server.py            # -> http://127.0.0.1:8321
py server.py 9000       # 自定义端口
```

首次启动时，若 `deals.json` 不存在，服务器会用 `gen_deals.py` 从
`../winexe/hands` 自动生成。然后在浏览器打开打印出的 URL 即可。

> 也可以随时用 `py web/gen_deals.py` 重新生成牌例数据。

## 文件

| 文件              | 作用 |
|-------------------|------|
| `server.py`       | 纯标准库 HTTP 服务器：提供静态文件 + `/api/deals`。 |
| `gen_deals.py`    | 把 5 个等级的牌例解析成 `deals.json`（并校验）。 |
| `deals.json`      | 牌例表（自动生成，无需手改）。 |
| `index.html`      | 页面：`#stage` 里放目录（TOC）与打牌界面。 |
| `style.css`       | 布局 + 自适应缩放的 `#stage` + 结算弹窗样式。 |
| `app.js`          | 打牌引擎（对应 `bm2000/playgame.py`）+ 画布渲染 + 自适应缩放。 |
| `selftest.html`   | 浏览器内冒烟测试（加载牌例、自动打样牌、缩放）。 |

## 自适应缩放

* `#stage` 是固定的 794×547 盒子。加载时与每次窗口大小变化时，
  `fitStage()` 会设置 `transform: scale(min(100vw/794, 100vh/547, 3))` 并居中，
  因此任意窗口尺寸 / 手机上都保持等比大小。
* 绿色牌桌是 `<canvas>`，按设备像素比绘制，文字清晰。

## 操作（游戏中）

* **点击** 你南家/北家手牌里被高亮的牌打出（**强制跟牌**；缺门时垫牌 / 吃张）。
  防守方自动领出并出牌。
* 工具栏：**重放 Replay**（重开这副）、**悔棋 Take back**（撤回上一步）、
  **单步 Step**（走一步防守）、**摊牌 Claim**（≥5 墩后可提前结束）、
  **讲解 Movie**（播放专家讲解）、**放大/缩小 Big/Small**（牌的大小）。

## 语言 — 中 / 英

网页版界面显示 **简体中文 或 English**，并自动选择：

* **自动检测** —— 加载时读取 `navigator.language`；值为 `zh…` 时用中文，
  其余用英文。即中文浏览器 / 终端打开即为中文界面，英文浏览器则为英文。
* **手动切换** —— 右上角 **EN / 中文** 按钮随时切换；选择存入 `localStorage`，
  下次访问自动记住。
* **URL 指定** —— 链接后加 `?lang=en` 或 `?lang=zh` 可强制指定语言
  （例如 `…/?level=1&deal=0&lang=zh`）。

整个 UI 会跟随所选语言 —— 标题栏、等级按钮、状态行、座位名（南/西/北/东）、
工具栏（重放/悔棋/单步/摊牌/讲解/…）、记分条（墩 / 局况 / 大牌）、讲解抬头、
以及结算弹窗（完成 / 未成，重新开始 / 显示答案 / 下一副）。
牌面、点数、花色和叫牌始终用标准记法（2–A、♠♥♦♣、1NT、4S、…），中英一致。

## 部署到 172.16.129.220

以 nohup 后台进程部署在内网服务器 `172.16.129.220`（CentOS 7，Python 3.6），
浏览器访问 **http://172.16.129.220:8321**。

    # 启动   （绑定 0.0.0.0:8321）
    bash /opt/bm2000/start.sh 8321
    # 停止
    bash /opt/bm2000/stop.sh

文件位于 `/opt/bm2000/`，`server.out` / `server.err` 为日志。部署要点：

* `server.py` 已做 **Python 3.6 兼容**（目标机是 3.6.8）：把 3.7 新增的
  `ThreadingHTTPServer` 导入换成自定义的 `ThreadingMixIn + HTTPServer` 类，
  并去掉了 `from __future__ import annotations`。
* 绑定 **0.0.0.0**（而非 127.0.0.1）以便内网访问；主机/端口可用环境变量
  `BM2000_HOST` / `BM2000_PORT` 或命令行端口参数配置。
* 目标机需在 **firewalld** 放行 **8321/tcp**
  （`firewall-cmd --permanent --add-port=8321/tcp`），否则内网无法访问。
* 随包附带 `deals.json`，因此目标机**不需要** `winexe/hands`，也不需要 Python
  `bm2000` 包 —— 纯静态文件 + 标准库即可。
* 这是 **nohup** 运行（按要求），不是 systemd 服务：**重启服务器后不会自动拉起**。
  如需常驻，请注册 systemd 单元或在开机脚本里加 `start.sh`。

## 备注

* 原始 `winexe/hands` 数据里有几条 `md` 值损坏、无法构成合法 52 张牌；
  `gen_deals.py` 会跳过它们（桌面版同样跳过）。最终保留 **530 副**可玩牌例。
* 网页版的防守策略与桌面版一致（见 `../analysis/GAPS.md`），并非完整对抗搜索。
* 每张牌会赋一个内部唯一 id，使得“点数+花色相同”的两张牌（数据里可能出现）
  仍被视为不同的牌；否则这种牌局无法打完。
