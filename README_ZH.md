# BridgeMaster2000 (bm2000) -- 桥牌大师 2000

[English](README.md)  ·  **简体中文 / Chinese**

《桥牌大师 2000》的一个忠实重现 —— 这是一个经典的
Windows 「教你作为庄家打桥牌」的教学程序。本项目包含
**两个同时提供**、共享同一套已验证的桥牌引擎的版本：

* **桌面版**（Python 3 + Tkinter），从 [页面](run.py) `run.py` 启动。
* **网页版**（原生 JS + canvas），由 [页面](web/server.py) `web/server.py` 提供，把原
  来 794×547 的“窗口”等比缩放以适配浏览器。

相同的 5 个等级、相同的约 530 副牌例、相同的游戏模型、相同的
专家讲解，以及相同的 **完成 / 未成（DEAL / FAILED）**结算弹窗。

> **范围 / 法律说明。** 本项目是通过研究该游戏的行为重新实现的，
> 随包提供从原程序提取的*牌例数据*和*帮助文件*，以保证游戏真实。
> 原始 **`bm2000.exe` 可执行文件未包含**在本项目中 —— 它是专有软件，被剔地排除。
> [外部](winexe/hands) `winexe/hands` 中的数据仅为让本仓库的代码可运行并能够与
> 原版对照验证。

## 游戏是什么

你打 **庄家 = 南家** + **明手 = 北家**。电脑打 **防御方 = 东家 + 西家**
（西家领出）。你唯一的目标是拿下当定约所要的堆数。**多堆无敌益**。

* 你同时打 **北家和南家** 两手牌。
* 电脑自动打东/西防御，采用标准防务约定（4 张以上出第四小、双张出大、
  光光 3 张出小；跟牌；合情时吃张）。
* **强制跟牌**：轮到谁只能从谁的手里出牌（另一手的牌不可点选、不高亮）。
* 打满 5 堆后可 **摊牌（claim）**；可播放专家「桥牌讲解（bridge movie）」、逐步
  退回，或 **惋棋**（撤回上一张）。

## 运行桌面版

```bash
cd <本仓库>

# 启动 Tkinter 界面（开场动画 → 目录 → 选副牌）
python run.py

# 直接打开某一等级/某一副牌
python run.py 1 A1

# 只列出等级及其牌例（不启动界面）
python run.py list
```

`run.py` 从 `./winexe/hands`（已包含）读取牌例数据从，从 `./winexe/BM2000.HLP` 读取帮助。

## 运行网页版

网页版**无需安装** —— 静态文件 + 一个很小的标准库服务器（同时在 `/api/deals` 提供牌表）。

```bash
cd web

# 默认端口 8321，绑定 0.0.0.0（内网可达）
python server.py            # -> http://<你的IP>:8321（localhost 也可以）

# 或自定义端口
BM2000_PORT=9000 python server.py
# 或
python server.py 9000
```

然后在浏览器打开 **http://localhost:8321**（或 **http://<服务器IP>:8321**）。页面会把 794×547 窗口
等比缩放以适合浏览器，在任意窗口尺寸 / 手机上都保持金虚模态。

> `deals.json` **已生成**并提交，网页版即取发可玩。重新生成（如改了数据）：
>
> ```bash
> python web/gen_deals.py    # 据 winexe/hands 重写 web/deals.json
> ```

### 网页版控件

* **点击**南家/北家手里被高亮的牌打出（只有轮到那手的合法牌可打；强制跟牌；缺门时吃张/垫牌）。
  防御方自动领出并出牌。
* 工具栏：**重放**、**惋棋**、**单步**、**摊牌**、**讲解**（播放专家解说）、**放大/缩小**。
* 结算：眼眼交替的 **完成**（成）/ **未成**（失）弹窗显示得分，并有
  **重新开始 / 显示答案 / 下一副** 按钮。

### 浏览器内自检

打开 `web/selftest.html`（通过 **http://localhost:8321/selftest.html** 服务）。它会加载全部 530 副牌、
把一个抽样牌例打到完成，并验证重视金视频。数据/引擎正常时打印
**`RESULT: ALL PASS`**。

## 游戏规则（两版通用）

桌面版与网页版都委托给同一套规则，行为一致：

* **进堆者** — 若非主色门被击出些主色则取其中最大的主色；否则取受门色中最大的牌。
* **合法出牌** — 若有受门色必须跟；否则可吃张（出主色）或垫牌。
* **领出轮转** — 进堆者领出下一堆；我方只能从实际轮到的北/南手里出牌。
* **结果** — 北+南拿到 ≥ 定约级数的堆即为*完成*；否则*未成*。

防务 AI 在两版都用同一套**约定**（不是深度对抗搜索）。这是已文书化的、故意的简化。

## 部署网页版到服务器

`web/` 中有一个 nohup 启动打脚。Python 3.6+ 的 Linux 机最小步骤：

```bash
# 1. 把 web/ 拷过去（它自含：静态 + deals.json + server.py）
scp -r web/* user@host:/opt/bm2000/

# 2. 在上乢启动，绑定 0.0.0.0:8321
cd /opt/bm2000
BM2000_HOST=0.0.0.0 nohup python3 server.py 8321 >> server.out 2>> server.err &

# 3. 让疫瓦振拨端口，例如 firewalld (CentOS):
sudo firewall-cmd --permanent --add-port=8321/tcp && sudo firewall-cmd --reload
```

然后从内网 **http://<机器IP>:8321** 访问。如需活重后仍可访问，请用 systemd 服务而非 nohup。
完整部署说明见 [页面结构](web/README.md) `web/README.md`。

> `web/server.py` 按 Python **3.6+** 编写（后置 `ThreadingHTTPServer`、避开 3.7 专属语法），默认绑定
> `0.0.0.0` 以供内网访问（`BM2000_HOST` / `BM2000_PORT` 可覆盖）。

## 校验本重现

共享引擎由自动化检查覆盖：

* **52 张守总定律** — 任意一副的完整自动扒结束时 52 张牌全部落入 13 堆，四手均为 0。
* **跟牌 / 轮到限制** — 只认可轮到那手的合法牌；非轮到/非跟色出牌被拒绝。
* **进堆者对定性** — 随机里兰牌盘与独立参考对照（100%一致）。
* **网页自检** — `web/selftest.html` 在浏览器里重击全部 530 副的抽样并验证不变量。

## 数据说明

* 5 个技能等级来自 `winexe/hands/<1..5>/{Index,Data}`。
* 原始数据中 5 条记录的 `md` 值损坏、无法构成合法的 52 张牌盘；两个版本**都自动跳过**它们，
  最终保留 **530 副可玩**（L1: 182, L2: 95, L3: 94, L4: 94, L5: 65）。
* `.LIN` 文件名在各等级间循环重用（例如每个等级都有 `A1.LIN` 但内容不同），所以牌例用
  `<分组>-<序号>` 代码（A-1, B-12, …）地址化，而非用文件名。
